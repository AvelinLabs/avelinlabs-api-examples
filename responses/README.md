# Response Fixtures

These files are evaluation fixtures, not substitutes for the API contract.

- Files named `.example.json` are illustrative unless explicitly documented as recorded.
- Placeholder values such as `<runtime-model-version>` are intentional.
- Notes about provenance belong in this file, not inside response JSON.
- Volatile identifiers and counts may differ between calls.
- Clients should ignore unknown additive fields.

The authoritative machine-readable contract is https://api.avelinlabs.com/openapi.json.
